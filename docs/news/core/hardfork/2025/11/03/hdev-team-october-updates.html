HDev Team October Updates

Nov 3, 2025 • hdev

First Monday of the month is when usually core Hive devs meet up to share some updates, great updates to be more accurate :) Now the topic of the hour (righteously so) is HF28

@hdev
First Monday of the month is when usually core Hive devs meet up to share some updates, great updates to be more accurate :) Now the topic of the hour (righteously so) is HF28. Alongside HF28, or version 1.28 of Hived core software, comes HAF suite of products that is currently powering many Hive API nodes, and more so as the hardfork unfolds. HAF packages many of the work our team has been working on across the last year, including this last month. ![image.png](https://usermedia.actifit.io/MHJNPGSBEW7H2XXQZT4T59GB4BZPV) Below we share key updates we highlighted in today's meeting to get a glimpse of our team's October updates. ### Front-end work Below features can be tested on [https://testexplore.openhive.network/](https://testexplore.openhive.network/) 1- **Account operations new filtering options (incoming/outgoing)**: This was a feature suggested by gtg, in alignment with the completion of the API endpoint in the prior month to allow filtering between incoming and outgoing transactions (part of a larger API change), so that when viewing a particular user's profile, you can choose to see what transactions they have performed (such as outgoing: this user voted on the other users' comments, or incoming: this user's post received votes from another user). This now constitues a part of the user profile section. You can see it on the testnet version of block explorer [here](https://testexplore.openhive.network/@arcange?&direction=exclude) ![image.png](https://usermedia.actifit.io/MHJKZW4YVIVYI8H5FSCYPYB7CWQBBI) 2- **User Profile Analytics: Interactive "Influence & Delegation" Map**: this includes an interactive chart showing delegations (incoming/outgoing) for this user, but also expands on other delegations by clicking on the nodes drawing a map of delegations across Hive (accounts). Check it out yourself by visiting an account at [https://testexplore.openhive.network/](https://testexplore.openhive.network/), or watch below video [![](https://ipfs-3speak.b-cdn.net/ipfs/bafkreigb53rt56ieqspq555dgpsdsjvkhesmm4jb5hgllh74uepstujtey)](https://3speak.tv/watch?v=hdev/bjfmajthko) 3- **DHF proposal's page chart** linking to proposals: The page includes a mini-funding status chart, which also links into each proposal by scrolling down to it to see further details ![image.png](https://usermedia.actifit.io/MHJLJZ4I5LFYNGQ3IGF54DT2DAXZI4) 4- **Add Translation Support to Health Checker:** Health checker is a separate component that powers both Block Explorer and Denser (for now) to be able to switch node and check node status. While both front ends support language switching, now the Component supports this as well so it does not look alianted when a different language has been picked by the user. ![image.png](https://usermedia.actifit.io/MHJMDW10AK4AKPUB24THZDKERVFO44) 5- **Add Transaction Byte Size** to the transaction view: This comes in really handy, particularly for devs trying to understand how much a given transaction has consumed in Bytes, within the transaction view. ![image.png](https://usermedia.actifit.io/MHJMAAL1EIHD94AGROQ27MNVE6AZI3) 6- **Implement HP/VESTS toggle** in user profile's balance mini-chart. While many aspects of the block explorer have already gotten this functionality, we just added it to the mini-balance chart. ![image.png](https://usermedia.actifit.io/MHJMOXEE296FDJ1SDG8E61LRKH91KC) 8- **Modular Dashboard:** This is a fantastic tool that is almost ready, enabling a complete dynamic reorganization and content creation of a user's dashboard. This will come mostly handy once we integrate authentication into block explorer for user customized experience and actions. You will have to wait to see it once merged, no sneak peek yet :) 9- **Add Market Execution Rate** for market order transactions: This comes in handy for anyone reviewing old transactions and at which rate was Hive bought/sold within a specific transaction. This covers both placing an order and order execution. ![image.png](https://usermedia.actifit.io/MHJMY95UEVQ6CA1CUS8QBE9FYE6BSO) 10- Linking wallet delegations values to delegators list in account profile page, whereby clicking on the value would lead to the delegators list for fast access. 11- Improvements to top holders page to include pagination & results count. 12- Improvements to search button sensitivity across the site to enable refetch data without criteria change. 13- Improvements to layouts, and new dynamic progress bar/circular graph layouts. ### Back-end work (HAF API): 1- **Handling of negative and zero block** numbers in several swagger APIs (Balance Tracker, Block Explorer, transfer-stats): This included fixes for special cases of APIs not returning proper error msgs/codes when negative or zero block numbers are requested. 2- **Top Holders API (Richlist)**: We recently created a richlist API endpoint as part of balance tracker, to query who are HIVE/HBD/VESTS/Savings top holders (accessible also via /topholders front end page), and we expanded this richlist to include pagination across all hive users and return total pages/results count. You can experiment with it [here]( https://api.syncad.com/#/Accounts/btracker_endpoints.get_top_holders) ![image.png](https://usermedia.actifit.io/MHJLQ1TN2COEGX4TVPD0MNMCA61KIQ) 3- **Expand proxied list API** to include more records: We also recently created a new endpoint that returns back who proxies their voting power to a particular account. We expanded this to cover more than 100 accounts (up to 1,000) to cater for few extreme cases on Hive. You can explore this [here]( https://api.syncad.com/?urls.primaryName=HAF+Block+Explorer#/Accounts/hafbe_endpoints.get_account_proxies_power) ![image.png](https://usermedia.actifit.io/MHJLTD042QPWJTVDWQBIXZR90WKMLP) 4- **Expose pending escrow balances** in account balances API: We had extended the account balances API to cover many new account data such as pending conversions, open orders, and more recently escrow pending transactions. You can explore this [here](https://api.syncad.com/?urls.primaryName=Balance+Tracker#/Accounts/btracker_endpoints.get_account_balances) ![image.png](https://usermedia.actifit.io/MHJLXJG0HGY6TRHCPHGLDXWHU85VUI) 5- We initiated a replay of one of our servers [devhiveapi](https://devhiveapi.actifit.io) to host version 1.28.1 of HAF. ### Support Our Work Our team of 6 devs would appreciate your support to continue our development efforts by voting for our DHF proposal (360). Thank you! - [Vote for our proposal on peakd](https://peakd.com/me/proposals/360) - [Vote for our proposal on ecency](https://ecency.com/proposals/360) - [Vote for our proposal on Hive wallet](https://wallet.hive.blog/proposals) - [Vote for our proposal via hivesigner](https://hivesigner.com/sign/update_proposal_votes?proposal_ids=%5B%22360%22%5D&approve=true)
