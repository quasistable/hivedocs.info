Development Updates - Hive Core Projects

Aug 18, 2025 • mcfarhat

@mcfarhat
It's been a while since we have provided large-scale updates (though we've shared weekly updates under swarm of swarms initiative ran by @hivetoday - thank you for including our content), So today, we are sharing some of the work our development team has been involved in over the last few months. The work spanned several hive projects, including: - [Hive Block Explorer (UI)](https://gitlab.syncad.com/hive/block_explorer_ui): Block explorer interface. We currently run a live instance at [hivescan.info](https://hivescan.info) - [Balance Tracker](https://gitlab.syncad.com/hive/balance_tracker/): HAF app providing end points for user account balances on Hive. - [Health Checker](https://gitlab.syncad.com/hive/healthchecker-component): a visual component that can be integrated into react front ends allowing checking, fetching and switching between Hive nodes - [HAF Block Explorer](https://gitlab.syncad.com/hive/haf_block_explorer/): HAF app providing information about transactions/operations included in Hive blocks ![image.png](https://usermedia.actifit.io/MEH39P5E2AXPQ8N97HTOM97ZHSXBP) The major areas of our work involved: - Revamp of several screens and components: Landing page, Voters modal, Voters History, User profile, ... - Expanded Hive chart display: with filtering capability and several display modes - Append savings display into Balance history page - Implement segmented search results display: this improves user search result visibility and clarifies bracket block range. - Show account incoming/outgoing recurring transfers, as well as followers/following modals. - Enhanced All blocks page + append live mode. - Enhanced date picker which includes Today selection option and better restrictions/matching for date/time - New cards on landing page, including Transaction stats, communities and others. - Searchable voters and votes list, but also expanded pagination and new chart components. - New complete Proposals page. - New Communities page and supported communities display on account pages, alongside subscribers and other data. - Tokenize Block Explorer and include language switcher supporting 12 languages. - Add dollar value display in balance history screen - Improve Health Checker display and functionality - Extended account balances endpoint: Expand account balances API endpoint to include market orders and balances under conversion. (Try it [here](https://api.syncad.com/balance-api/accounts/blocktrades/balances)) - New API endpoint for Hive's Richlist: This enables querying top holders according to their HIVE/HBD/HP or even savings balances. (Try it [here](https://api.syncad.com/balance-api/top-holders?coin-type=HIVE&balance-type=balance&page=1)) - Other code improvements and bug fixes For the more technical, below is a breakdown of issues completed and pending pipeline across all 4 projects #### Issues Completed (134): These include bugs and enhancements: ++Block Explorer UI:++ -
