This is another update on the work done over the last month by myself and several part-time resources that I have onboarded to learn about Hive and its technologies, and is separate from the work we do in developing & growing Actifit, for which we have a separate team. During this iteration, and in addition to our work on Block Explorer UI and Balance Tracker, we further expanded our involvement to include denser, the condenser successor. ![image.png](https://usermedia.actifit.io/LYJ62O3LETBMJRG51HNL8W2NFJ1WB) For those unaware, HAF Hive block explorer - HAFBE (code - [gitlab link](https://gitlab.syncad.com/hive/block_explorer_ui)) is an open-source block explorer developed by @blocktrades team of which we currently run a live instance at [hivescan.info](https://hivescan.info). Denser is an open-source replacement for condenser, i.e. the code base behind [hive.blog](https://hive.blog). You can find the codebase [here](https://gitlab.syncad.com/hive/denser). We have recently setup a dev environment for both wallet and blog components running at 78.46.16.241:3000 and 78.46.16.241:4000 As usual, our work was focused on improving the user experience by suggesting and/or implementing functionality that we deem useful visually, reporting issues and improvements related to mobile view, dark mode, branding as well as witness details such as block production schedule.
