Hive Keychain Mobile 2.4.3 + Extension production release : Multisig and 2FA

Nov 25, 2024 • keychain

The extensions spent a little while in Beta after the introduction of the 2FA features, and was ready after a few tweaks

@keychain
![New Hive Multisign Proposal.png](https://files.peakd.com/file/peakd-hive/keychain/23wByQ9g5ZZJRA9UJToNaPHKmcPKbJ1oMmcikNHSbZERcjyAzp124unhJHEyyS2s5GWy7.png) The extensions spent a little while in Beta after the introduction of the 2FA features, and was ready after a few tweaks. We kept it in Beta longer, waiting for the same feature to be released on mobile. If the 2FA is required for an account, you should be able to use it on every platform, and that is now the case, starting with Keychain mobile v2.4.3!

Multisig

Keychain mobile can now automatically detect when a transaction needs several signatures and process the operation through Hive Multisig when needed: https://images.hive.blog/500x700/https://files.peakd.com/file/peakd-hive/keychain/23xyGTni4yxV12z7eTrFwtAErr772yDJFSyN8cVqk5HSbByQmtqK7GsD6EAKkERKR61hZ.png Accounts can also be set to listen for Multisig requests in Menu > Settings > Multisig: https://images.hive.blog/500x700/https://files.peakd.com/file/peakd-hive/keychain/23wWTFGjZUN5u4VEf5D8WbL77DEHYvVeaLq1PqwHBz4sqvprjSjV1UAsG3Bp2k6T3f4pQ.png https://images.hive.blog/500x700/https://files.peakd.com/file/peakd-hive/keychain/23xV8FpGzXUCX21RJWevxPod3jbWQkKrbTnSXsbraB8iFxng3FbMjUAGZmC7nCkZZRqH7.png

2FA
