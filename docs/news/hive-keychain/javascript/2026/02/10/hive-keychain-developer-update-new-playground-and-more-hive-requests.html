Hive Keychain Developer Update — New Playground and More Hive Requests

Feb 10, 2026 • keychain

We’re excited to announce a major Hive Keychain release, primarily focused on developers and teams building on Hive

@keychain
![2.png](https://files.peakd.com/file/peakd-hive/keychain/245J1kwBWtzUJ4N19DLtkyMKZTHDGRj545yGUv381BrXTujhmEW1SmLshZutAdE2VgpgD.png) We’re excited to announce a major Hive Keychain release, primarily focused on developers and teams building on Hive. This update improves how developers learn, test, and integrate Keychain by revamping core tooling, expanding available requests, and introducing more flexible interaction patterns across the extension, mobile apps, SDK, and Playground. These improvements are now live across the Hive Keychain ecosystem. ---

A Revamped Playground Experience

![3.png](https://files.peakd.com/file/peakd-hive/keychain/23uFu4mW39qJY6ZGSv5RR3KGcyd72BPAJwZjVQjP71yvS8Lq9TbM8Eh73DoGnE8qk67Ci.png) The Hive Keychain Playground has been fully redesigned, and here is what is new: - A cleaner, more structured layout - A navigation style inspired by GitBook-style documentation - Easier discovery of available requests and parameters - A smoother experience when testing transactions and flows The goal is simple: make it easier for developers to explore Keychain capabilities, test integrations quickly, and understand how each request behaves without friction. Check out our brand new [Playground](https://play.hive-keychain.com/) and comment below with your thoughts. ---

Savings Requests Now Supported Everywhere

We’ve added full support for Savings-related requests across the Keychain ecosystem. It is available in all our products, and developers can now request deposits and withdrawals from savings. All use the same consistent API and UX patterns already familiar from other Keychain requests. ---

More Requests Can Now Be Anonymous

We’ve expanded support for optional, user-selected account usage in several Keychain requests. The following requests can now be made without predefining a username: - Vote - Convert - Power Up - Send Token Instead of forcing the dApp to specify the account, users can now choose the account themselves via a dropdown inside Keychain. This will improve the experience for multi-account users, remove friction for dApps that don’t manage user identity directly, and add more privacy friendly request flows. This flexibility makes Keychain easier to integrate into a wider range of use cases. ---

Built for Developers, Shaped by Feedback

Many of these improvements come directly from developer feedback, dApp integration discussions, and community conversations on Discord. Our goal is to reduce friction at every step to improve how developers can ship production-ready integrations. All the good news from today is supported in the following versions of our products: - **Extension: 3.13** - **Mobile: 2.12 (pending review on iOS)** Do you have a request for a new feature or some feedback that can help you improve how you integrate Hive Keychain? Our development team is here for you.
