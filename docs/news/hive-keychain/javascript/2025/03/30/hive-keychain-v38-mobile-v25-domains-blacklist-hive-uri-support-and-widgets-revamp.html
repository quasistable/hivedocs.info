Hive Keychain v3.8 + Mobile v2.5 : Domains blacklist, Hive URI support and widgets revamp

Mar 30, 2025 • keychain

We've just released an update to both our extensions and mobile Apps that add the following features and improvements

@keychain
![social_keychainforhive.jpg](https://files.peakd.com/file/peakd-hive/keychain/xnmVXGi6-social_keychain-for-hive.jpg) We've just released an update to both our extensions and mobile Apps that add the following features and improvements

Domains Blacklist

We are now showing a warning on extensions and mobile Apps if the domain making a Keychain request has been flagged as suspicious. https://files.peakd.com/file/peakd-hive/stoodkev/23uRFeePQ1k1jcQciNpuAr868FdW1brHC1yk2e8YX4YJLN81zQvPr91X7RspLBdpdvKXf.png A big thanks to @themarkymark for suggesting the feature and @keys-defender for providing the blacklist.

Hive URI support

Did you know you can request transactions using a `hive://` link and generate a QR Code that can be scanned by Keychain mobile users? You can use [this tool](https://qr.hive-keychain.com/) to generate these links. In addition to transfers, delegations, witness, and proxy transactions, we've just added support for recurrent transfers and proposal votes. We've also added this feature to the extensions; a simple link can now become a Keychain request. For example, scanning this QR Code or clicking this link will request a vote for the Keychain proposal: Note that at this time, Hive schemes are working on PeakD (thanks to @asgarth), pending review on Hive.blog (thanks to @quochuy), and Ecency is working on integration (thanks to @good-karma). Still waiting to hear from @leofinance at this point.
