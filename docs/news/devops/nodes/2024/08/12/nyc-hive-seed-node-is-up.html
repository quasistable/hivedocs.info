NYC Hive Seed Node Is Up

Aug 12, 2024 • rishi556

4 nodes right now(will be 3 soon, sad to say bye to Kansas City node, but hard to keep all the lights on, and Chicago is close enough) in the cluster keeping it alive all running under hiveseed.rishipanthee.com

@rishi556
And that completes the US cluster. 4 nodes right now(will be 3 soon, sad to say bye to Kansas City node, but hard to keep all the lights on, and Chicago is close enough) in the cluster keeping it alive all running under `hiveseed.rishipanthee.com`. Just add that to your config and you'll be using them. This final seed node is using F4's server in Brooklyn, NYC at Datavere's DC: https://dataverge.com/interconnected-data-center-brooklyn/.
