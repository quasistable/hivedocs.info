New Upgraded Hive HAF API Server

Apr 12, 2024 • actifit

We are excited to announce our new and upgraded server for running Hive API/RPC node

@actifit
![image.png](https://usermedia.actifit.io/LKQOA2281G38LE1FHJRKQAGSR5ZW0A) We are excited to announce our new and upgraded server for running Hive API/RPC node! Our old server was causing issues frequently, so we decided to make a big leap in our infrastructure supporting hive blockchain, and hence we brought in the big guns. As of today, we are proud to be back up and running our official hive API node accessible via https://hiveapi.actifit.io #### Software & Version The node is currently running HAF v1.27.5, this was made possible via the amazing effort by @blocktrades and team, who streamlined the whole setup process [here](https://gitlab.syncad.com/hive/haf_api_node) and provided support along the way. The server is running hived, alongside haf apps hivemind, HAFAH and haf-block-explorer services as backend services #### Hardware Specs Our server has quite solid numbers behind it, below are the specs: - CPU: AMD Ryzen 9 7950X3D (32 cores) - RAM: 128 GB (DDR 5 ECC) - SSD: 2 x 1.92 TB (Gen 4) NVMe (ZFS data storage) + 1 x 960 GB (Gen 4) NVMe (Boot). You are welcome to use our node as it's a public node. It is already listed alongside the other API nodes under https://beacon.peakd.com ![image.png](https://usermedia.actifit.io/LUX68I0QTLOA0XK61ULJKT70UYVWV) #### Support Our Work - Our 2023 review and new proposal for 2024 is out!
