Generated with Illusion Diffusion HQ # Upgrades (new release) If you haven’t done so yet, please upgrade your nodes to version `1.27.6`. This version includes a fix in the p2p code to avoid crashes in certain circumstances. Despite the release being over a month ago, only 4 nodes within the top 20 have upgraded, and there are only 19 upgraded witnesses in total. Additionally, we are anticipating the next HardFork (a.k.a. major upgrade) in September. I expect witnesses to be on the latest version of hived from the `1.27.x` line by then (there will be at least one minor release, hopefully soon). # Useful Resources: https://gtg.openhive.network I’ve removed all older versions from my site, including their respective snapshots. On the other hand I’ve just updated a lot of resources, including: - Old school Hivemind database dump - Old school account history node snapshot - Exchanges node snapshot (for exchanges, seeds, witnesses, broadcasters, etc.) Regarding “Old school” nodes, please don’t expect future updates. While they might still be viable in certain scenarios, maintaining their snapshots is resource-intensive. I will keep the last versions for reference. ### API node operators are strongly advised to use `haf_api_node` instead. For the record: - 300GB is the uncompressed Hivemind dump (`-Fd -Z0`), roughly 60GB after compression (`lbzip2`) - 700GB PostgreSQL data storage - 1.6TB account history data directory, which includes: - 475GB current block log with artifacts. - 22GB current shared memory file. - 1.1TB account history node snapshot (uncompressed) - it takes 25 minutes to dump it. - 713GB compressed snapshot (takes 1 hour to compress it). # Checklist For non-witness readers who might find this post boring, here’s a simple excercise with a security checklist: - Do you have your keys stored securely? - Do you have your recovery partner set to someone who can help you recover if needed? - Do you take an active part in Hive governance? If you answered "**YES**" to all three, please leave a comment below :-)
