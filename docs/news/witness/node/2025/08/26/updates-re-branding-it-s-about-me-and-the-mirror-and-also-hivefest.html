Witnessing Angkor, Cambodia, 2016. # Mirror When it comes to the mirror, it's about time to try the new versions of the software we are developing. I just started the conversion using 98880088 blocks from mainnet (courtesy of @blocktrades and @thebeedevs hardware resources, using CI/CD pipelines). The old instance (p2p consensus nodes and simple API) is still running, unfortunately, the full API is no longer available due to an unfortunate chain of events, and bringing it back now would slow down the initialization of the new one, which should happen in a few days. Note to self: I should remember to use a custom value for the `TOTAL_NUMBER_OF_BLOCKS_TO_PROCESS` variable while running the mirrornet conversion, otherwise, it uses a default that is too far in the past. Also, let's schedule a mirrornet hardfork 28 (yet another) for September 1st 14:00 UTC, shall we? Coordination on https://openhive.chat/channel/witness because otherwise I would be repeating similar content over and over again about mirror instances in my posts, which is simply boring for most people here.
