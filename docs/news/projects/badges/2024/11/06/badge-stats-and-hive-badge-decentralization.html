BADGE STATS and Hive Badge Decentralization

Nov 6, 2024 • peak.open

Hive Open Stats projects now has stats for badges

@peak.open
![image.png](https://files.peakd.com/file/peakd-hive/peak.open/EqNKYUwTc4z5z3nDdksW8SLFMqA4HpAWWBPZ17AVZ1cAJ6BBdCsGv1SZUCPSA1wr3rD.png) # Decentralizing Hive Badges with HiveHub Tools We're excited to help make **Hive Badges** more decentralized by providing tools for different Hive apps and UIs to customize badge usage to suit their needs. ![Hive Badges](https://files.peakd.com/file/peakd-hive/peak.open/23tHXEzHEyT96VhCdjqqxwRFR1LUzQz6wWJ7z9VHtsyT35koEHdBtdP64ZwY3k5A1ByMS.png) ### Badge Creation Anyone can create a badge, and we'll feature it on the [HiveHub Badge Stats](https://hivehub.dev/stats/badges) page: ``` How to Create a Badge: 1. Create an account @badge-{6 digits} 2. Give it a name 3. Edit description for what the badge is about 4. Follow other accounts with this account It really is that easy ``` ### Stats for Hive UIs We provide Hive UIs with badge stats to help them make informed decisions on which badges to display. These stats are also a fun resource for users to explore the badges they've received and guide them in choosing badges they may want to follow: ![Badge Stats](https://files.peakd.com/file/peakd-hive/peak.open/23xVitxe1yaKa8z7oxwov11vVgE3Ci1XcumCpBzcoULTNpVmABR7Fwat1z2zQ5M5pibW1.png) ### Active Badge Recipients One of our favorite new stats highlights how many badge recipients have been active over a set period—such as the last 30 days. Other time frames can be used via API as needed: ![Active Badge Recipients](https://files.peakd.com/file/peakd-hive/peak.open/23yU6docwMUfqichTHJT86V3TvrMe1xNe7feLgpVta1nueYhpETK5sQEgwuTzEcVf9cT8.png) ### A Team Effort The new Hive stats metrics are powered by: - **@borislavzlatanov** for badge data - **@mahdiyari** for HAFsql assistance - **@yozen** for UI contributions with help from **@asgarth** and **@jarvie** As usual @peak.open creates open source tools. Hivehub.dev is our opensource way to display some of the tools but we invite any website to do so themselves. --- ## Decentralization & Customization: The PeakD Filter Any Hive UI can now filter which badges to display, allowing apps to tailor their badge experience. While Hive Badges are decentralized and don’t require our help, we’re making it easier for apps and users to access badge information, identify abandoned badges, and appreciate those valued by users. **Stay Tuned:** @peakd will announce updates to their badge page soon and also their updated criteria for identifying abandoned badges and what badges will be assigned to users. **Want to use Badges on your site?** If you’re a UI developer interested in customizing your badge page, consider creating a 'badge of badges' to represent badges relevant to your users. Reach out if you'd like a custom filter on the [HiveHub Badge Stats](https://hivehub.dev/stats/badges) page by providing your badge account. ![image.png](https://files.peakd.com/file/peakd-hive/peakd/23wX9cuQUkiVELkWSvAUmghvj9hafoutEypsevvHjbr9dW9wiChCMrg5qSBvsP6BkgFct.png) ---- ## Call to Action **Vote for our proposals here:** https://peakd.com/me/proposals/peakd Specifically this proposal is still not funded: https://peakd.com/me/proposals/311 --- Published with **[PeakVault](https://vault.peakd.com)** [![](https://files.peakd.com/file/peakd-hive/peakd/23uFHFH9niedvvByM7oWY7YGno8CnGqNHEBcgCe2wmAakRBfP2uMBo6LpysmqDtxaRVxC.png)](https://vault.peakd.com)
