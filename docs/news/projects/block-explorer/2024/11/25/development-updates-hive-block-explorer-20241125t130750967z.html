Development Updates - Hive Block Explorer

Nov 25, 2024 • mcfarhat

This is another update on the work done over the last few weeks by myself and the development team assigned to Hive Block Explorer and related projects

@mcfarhat
This is another update on the work done over the last few weeks by myself and the development team assigned to Hive Block Explorer and related projects. ![image.png](https://usermedia.actifit.io/LYJ62O3LETBMJRG51HNL8W2NFJ1WB) For those unaware, HAF Hive Block Explorer - HAFBE (code - [gitlab link](https://gitlab.syncad.com/hive/block_explorer_ui)) is an open-source block explorer developed by @blocktrades team of which we currently run a live instance at [hivescan.info](https://hivescan.info). Our work was focused on introducing new functionality to HBE including more visible data and more flexibility in the display of this data whether on a user's page, block view, or witnesses display, but also integrating some community suggestions that we deemed useful, alongside many enhancements, bug fixes, and better integrations with the backend components.
