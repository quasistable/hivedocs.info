Development Updates - Hive Block Explorer UI

Jul 29, 2024 • mcfarhat

Over the last 2 weeks, we've done additional work to help out with the development and improvement of HAF Block Explorer's UI

@mcfarhat
Over the last 2 weeks, we've done additional work to help out with the development and improvement of HAF Block Explorer's UI. This is work done by myself and several part-time resources that I have onboarded to learn about hive and used technologies, and is separate from the work we do in developing & growing Actifit, for which we have a separate team. ![image.png](https://usermedia.actifit.io/LYJ62O3LETBMJRG51HNL8W2NFJ1WB) For those unaware, HAF Hive block explorer - HAFBE (code - [gitlab link](https://gitlab.syncad.com/hive/block_explorer_ui)) is an open-source block explorer developed by @blocktrades team of which we currently run a live instance at [hivescan.info](https://hivescan.info). Over the past two weeks, our work has been focused on improving the user profile page by appending sections related to outgoing delegations (HP/RC), but also improvements to the witnesses page displays and identifying and assisting with overall bug fixes. Below is a breakdown of reported issues, enhancements, MRs and issues under work. #### Issues Reported (5): These include bugs and enhancements to the block explorer's functionality. - opened issue [#295](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/295) "Improve witnesses display of feed age" - Opened issue [#296](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/296) "Add sorting capability to the witnesses list" - Opened issue [#297](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/297) "Add "Last Block Produced" column/field in witnesses listing page" - Opened issue [#301](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/301) "add a "hide disabled witnesses" toggle at top of witnesses page" - Opened issue [#302](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/302) "Page crash when loading user profile" #### Merge Requests Pushed (6): These include bug fixes and enhancements related to the above issues, and which all have been merged. - Opened merge request [!354](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/354) "resolve 286 enhancement - add witness vote count" - Opened merge request [!357](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/357) "implementing vesting delegations card - issue 284" - Opened merge request [!359](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/359) "adjust strikethrough of witness to cover entire row (ref issue 287)" - Opened merge request [!360](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/360) "implement RC delegations box related to issue 285" - Opened merge request [!361](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/361) "fix crash issue when loading certain user profiles - 302" - Opened merge request [!363](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/363) "implement enhancement per issue 295 for feed age display" #### Currently Assigned Issues / Under Works (6): - Add live Tracking on a user profile display [283](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/283) - Create new user page box display with title "Delegations (RC)" [285](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/285) - Add sorting capability to the witnesses list [296](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/296) - Add "Last Block Produced" column/field in witnesses listing page [297](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/297) - Account balances should be displayed more prominently [303](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/303) - All calls to node should use Wax [307](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/307) We look forward to contributing more to the Hive ecosystem and will provide further updates in the coming weeks. -
