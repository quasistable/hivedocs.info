Development Updates - Hive Block Explorer

@mcfarhat
Aside from the work we do in developing & growing Actifit, as well as promoting Actifit and Hive, and with the help of a few development resources I have around, we recently started getting more involved in the development of additional tools that help Hive grow. One of those tools is hive block explorer - HBE (code - [gitlab link](https://gitlab.syncad.com/hive/block_explorer_ui)) an open-source block explorer developed by @blocktrades team that we currently run a live instance of at [hivescan.info](https://hivescan.info). ![image.png](https://usermedia.actifit.io/LYJ62O3LETBMJRG51HNL8W2NFJ1WB) Over the past two weeks, my team and I have made the following effort to improve HBE: #### Issues Reported (9): These include bugs and enhancements to the block explorer's functionality. - Opened issue [#291](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/291) "User page erroring out for specific user" - Opened issue [#290](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/290) "Hovering over block record highlights row except block number & messes tooltip" - Opened issue [#288](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/288) "Add timestamp tooltip display on hover over time record in the user's transaction/profile display" - Opened issue [#287](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/287) "Show disabled witnesses in a strikethrough display" - Opened issue [#286](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/286) "Add number of votes on an individual user's witness votes box title" - Opened issue [#285](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/285) "Create new user page box display with title "Delegations (RC)" - Opened issue [#284](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/284) "Create new user page box display with title "Delegations (Vesting)"" - Opened issue [#283](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/283) "Add live Tracking on a user profile display" - Opened issue [#282](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/282) "Fix issue with operations per block count showing empty" #### Merge Requests Pushed (5): These include bug fixes and enhancements related to the above issues, and which all have been merged. - Opened merge request [!350](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/350) "fix for issue 282 - missing trx count" - Opened merge request [!344](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/344) "fix hovering issue referenced in issue 290" - Opened merge request [!343](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/343) "implement timestamp tooltip display on hover - issue 288" - Opened merge request [!338](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/338) "Fix last final rows missing border separator in witness list box" - Opened merge request [!337](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/337) "Adjust user profile witness box list display to alphabetical sorting" We look forward to contributing more to the Hive ecosystem and will provide further updates in the coming weeks. - Support our witness @actifit on Hive, vote for us or set us as proxy on [actifit profile](https://actifit.io/actifit), or via [peakd](https://peakd.com/witnesses), [hive blog](https://wallet.hive.blog/~witnesses) or [hive-signer](ttps://hivesigner.com/sign/account-witness-vote?witness=actifit&approve=true). - Support our witness @actifit-he on Hive-engine, vote for us on [Tribaldex](https://tribaldex.com/witnesses).
