Development Updates - Hive Block Explorer UI

Aug 19, 2024 • mcfarhat

Over the last 3 weeks, we've done additional work to help develop and improve HAF Block Explorer's UI

@mcfarhat
Over the last 3 weeks, we've done additional work to help develop and improve HAF Block Explorer's UI. This is work done by myself and several part-time resources that I have onboarded to learn about Hive and used technologies, and is separate from the work we do in developing & growing Actifit, for which we have a separate team. ![image.png](https://usermedia.actifit.io/LYJ62O3LETBMJRG51HNL8W2NFJ1WB) For those unaware, HAF Hive block explorer - HAFBE (code - [gitlab link](https://gitlab.syncad.com/hive/block_explorer_ui)) is an open-source block explorer developed by @blocktrades team of which we currently run a live instance at [hivescan.info](https://hivescan.info). Over the past few weeks, our work has focused on improving the user profile page by appending sections related to overall wallet balances, improvements to the witnesses page displays, refactoring some of the code, as well as and identifying and assisting with overall bug fixes and improvements to the backend querying and indexing mechanisms. Below is a breakdown of reported issues, enhancements, MRs, and issues under work. #### Issues Reported (3): These include bugs and enhancements to the block explorer's functionality. - opened issue [#312](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/312) "Filtering by dates is overlapping on mobile view" - Opened issue [#77](https://gitlab.syncad.com/hive/haf_block_explorer/-/issues/77) "Add data to get_witnesses end point" (_this is under HAF Block Explorer project NOT the UI project_) - Opened issue [#308](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/308) "Add link to witness announcement post on witnesses page" #### Merge Requests Pushed (8): These include bug fixes and enhancements related to the above issues, and which all have been merged. - Opened merge request [!379](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/379) "implement fix for date filtering UI overwriting text" - Opened merge request [!378](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/378) "implement disabled witnesses filtering" - Opened merge request [!377](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/377) "improve on our original implementation for live profile tracking" - Opened merge request [!373](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/373) "implement live profile tracking - enhancement 283" - Opened merge request [!370](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/370) "adjust formatting in user's wallet box" - Opened merge request [!368](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/368) "Implementing new wallet box which includes display of wallet info, price conversion,..." - Opened merge request [!367](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/367) "Refactor code to use WAX and other recommendations per issue 307" - Opened merge request [!365](https://gitlab.syncad.com/hive/block_explorer_ui/-/merge_requests/365) "formatting RC & Vests value delegations" #### Currently Assigned Issues / Under Works (3): - Account balances should be displayed more prominently [303](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/303) - Add "Last Block Produced" column/field in witnesses listing page [297](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/297) - Add live Tracking on a user profile display [283](https://gitlab.syncad.com/hive/block_explorer_ui/-/issues/283) We look forward to contributing more to the Hive ecosystem and will provide further updates in the coming weeks. -
