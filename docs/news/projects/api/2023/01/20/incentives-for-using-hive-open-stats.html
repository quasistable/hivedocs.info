Incentives for using Hive Open Stats

Jan 20, 2023 • peak.open

Incentives for developers and content creators to utilize the open source Hive Stats project

@peak.open
![PeakMonsters Cover.png](https://files.peakd.com/file/peakd-hive/mozzie5/23vrrxMCmNsWZk3vwn5iu9s3ntDMRqfzkrhfpCJ8SuwfCs9cNzuc1opJ7nKY6wgteS1sD.png) The [open source Hive Stats project](https://gitlab.com/peakd/hive-open-stats) is moving right along with APIs for Hive based stats and [HiveHub.dev](https://hivehub.dev/stats) is the first site to make charts for many of these APIs provided by the open source project. *But we don't want to be the only site using these stats...* ![Screenshot 2023-01-05 at 9.20.09 PM.png](https://files.peakd.com/file/peakd-hive/mozzie5/23tkhh6V5VV2KHWU9CQYE2ccKtSp7FmuVBsoQDtfzZ2oJdkVW3aeVmgnhM9K3geJtmoUp.png) **INCENTIVES FOR USING THE STATS** We would love to invite and perhaps **incentivize other developers to use the API** to create charts that interpret all these data points in their own beautiful or creative way. That's why we are offering some of the funding the Peak Open Projects has received to websites and their developers who make use of this data. *This unique Hive data is not meant to exist on hivehub.dev alone.* We would also like to invite content creators to use the data or screenshots from [hivehub.dev](https://hivehub.dev/stats) in posts and interpret the data in their post. Please share your posts about the Peak Projects website in the #posts-about-peakd channel in our [discord](https://discord.gg/QdYg3zUSCD), and we will make sure to vote and promote the posts and even give HIVE or HBD tips to awesome content. ![image.png](https://files.peakd.com/file/peakd-hive/peak.open/EpviSXLHgPBzxSxTShL6tpQKJRaNgewXS9nh4REPDfk26DaA9s1CPP3h4PLR36QwRoP.png) HiveHub.dev has created 24 charts from the API data, and many more can be created in unique ways... we are interested to see what you do with them. ![Sample Stats on HiveHub](https://files.peakd.com/file/peakd-hive/mozzie5/23tGVGBukyYerkRENdcKCett7taiedERptvC3yxY5FME3gZyVR3Qi1fRB3YZy6TcATsS7.png) -------- **OPEN SOURCE** https://gitlab.com/peakd/hive-open-stats --- **NEXT UP: COMMUNITIES** Next set of stats being worked on is communities with the data already being made available and charts coming soon. We would love to see all the blogging sites start to use these stats for communities as well. Then... users... **SUGGESTIONS?** Do you have a Hive based stat that you love? Share it in the comments and we'll see if we can add it to the project. --- ![Selection_298.png](https://files.peakd.com/file/peakd-hive/peakd/w36DQpO7-Selection_298.png) ## How to support the @peakd project **WORK WITH US** If you're a project looking to integrate one of these tools message us. If you're a developer looking for a part time open source project message us. **WITNESS VOTE** We have been voted as a top block producer on hive (aka "witness"). You can add your vote for us on the main [witness page](https://peakd.com/witnesses) our "witness" account is @steempeak VOTE HERE: https://peakd.com/witnesses **OPEN PROJECTS PROPOSAL** You can support our proposal to develop open source tools for the whole Hive community using one of the following links: - PeakD: https://peakd.com/proposals/223 - Hive.blog: https://wallet.hive.blog/proposals - Ecency: https://ecency.com/proposals/223 - Or directly on [Hivesigner](https://hivesigner.com/sign/update-proposal-votes?proposal_ids=%5B223%5D&approve=true) **BENEFICIARY** You can donate 5% of your Hive Reward Pool earnings to @peakd to help use improve the interface: [Turn on in settings](https://peakd.com/me/settings/general) **SHARE IDEAS AND FEEDBACK** We invite you to share and brainstorm some ideas with us: - Share on posts #HiveLaunchpad or #PeakOpenProjects - Reach out on [this discord channel](https://discord.gg/qfZDnKqT4a) - Create a suggestion on our new feature voting site https://feedback.peakd.com -- use category "Peak Open Projects" --- **The PeakD Team** _About us: https://peakd.com/about_ [Discord](https://discord.gg/Fy3bca5) - [Blog](https://peakd.com/@peakd) - [Twitter](https://twitter.com/peakdcom) - [LinkedIn](https://www.linkedin.com/company/peakd/)
