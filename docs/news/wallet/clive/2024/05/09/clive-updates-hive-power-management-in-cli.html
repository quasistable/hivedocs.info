Clive Updates - Hive Power Management in CLI

May 9, 2024 • thebeedevs

The main feature delivered in this release is Hive Power Management in CLI (command line interface)

@thebeedevs
The main feature delivered in this release is Hive Power Management in CLI (command line interface). The Hive Power Management is already available in TUI (text-based user interface). You can read about it in our previous posts: - [CLI authority management and TUI Hive Power management](/@thebeedevs/clive-updates-cli-authority-management-and-tui-hive-power-management) - [TUI Hive power management is now completed](/@thebeedevs/clive-updates-tui-hive-power-management-is-now-completed) ### Hive Power Management in CLI Using Hive Power Management in CLI, the user may make a power up, power down, set withdrawal routes, and delegate Hive Power. Additionally, the user may check information related to Hive Power. ##### Check information about Hive Power The general information about Hive Power Management, such as VESTS/Hive Power balances, processed power down operation, defined withdrawal routes, and delegations may be checked using the following command: `clive show hive-power` `Next withdrawal` shows the date when the next part of the vesting stake will be converted into Hive. `To withdraw` shows the amount of Power down operation. ![clive show hive-power](https://images.hive.blog/DQmPPmP7MoPq9kWctaYTngoswuvkjcjSwNAonZh7WZYQYCQ/image9.png) ##### Check information about pending power-up The vesting shares balance after the Power-up operation is increased immediately, but the Governance voting power is delayed and will be increased after 30 days. To check information about delayed votes, a user may use the following command: `clive show pending power-ups` ![clive show pending power-ups](https://images.hive.blog/DQmeEUTvUksS8y8fjPrPcrtq6XaCQti4vh7qBXcNAQTkvph/image7.png) ##### Check information about pending power-down The information about the next withdrawal of the power down in progress may be checked with the following command: `clive show pending power-down` ![clive show pending power-down](https://images.hive.blog/DQmXGF7gwPf24DxoHEaZp8YF3bdjVsADHGRJiP4M5wz9vdN/image6.png) ##### Check information about pending removed delegations If the delegator removes the vesting shares delegation, the vesting shares are frozen for one week. You can view the frozen vesting shares using the following command: `clive show pending removed-delegations` Example from testnet: ![clive show pending removed-delegations](https://images.hive.blog/DQmVJfyBAj4G9NF97it5c61Q1DmqwfnwecBz82mgg7c8pri/image12.png) ##### Power up in CLI A user may make a power up using [transfer_to_vesting_operation](https://github.com/openhive-network/hive/blob/master/doc/devs/operations/03_transfer_to_vesting.md) via `clive process power-up` command. ![clive process power-up](https://images.hive.blog/DQmbL1vUzFG9t74Rg1eHHeMF7onFgaA4R2m7rN4kZySC2eS/image8.png) Example: A user wants to make a power up for 0.1 HIVE amount. `clive process power-up --amount "0.1 HIVE" --sign alias1 --password alicealice` ![clive process power-up --amount "0.1 HIVE" --sign alias1 --password alicealice](https://images.hive.blog/DQmU88GsbW7iVX9YwazatSJZBwRoBFZepseMSfhpTvj8h2o/image11.png) ##### Power down The user may start a power down process using [withdraw_vesting_operation](https://github.com/openhive-network/hive/blob/master/doc/devs/operations/04_withdraw_vesting.md) and Clive CLI subcommands of `clive process power-down`. In Clive CLI mode, the user may start, restart (create a new power down when an old power down is in progress, the old power down is canceled ), or cancel a power down. ![image5.png](https://images.hive.blog/DQmdynDDpdhiHdAPDkgY87UuyP3G152eueoma6QZnLoJKex/image5.png) Example: The user wants to change the amount of power down. The user wants to check what the operation that changes the amount of power-down looks like. That is why they use the `no-broadcast` flag. `clive process power-down restart --amount "0.02 hive" --no-broadcast --sign alias1 --password alicealice` ![image4.png](https://images.hive.blog/DQmV3kjEQBxRV8KAtRyTjfQZEvvjo2DZrTUr1b9b7jdsvBg/image4.png) ##### Setting withdraw routes The user may set withdrawal routes using [set_withdraw_vesting_route_operation](https://github.com/openhive-network/hive/blob/master/doc/devs/operations/20_set_withdraw_vesting_route.md) and `clive process withdraw-routes` subcommands. In CLI Clive the user may set or remove a withdrawal route. ![image2.png](https://images.hive.blog/DQmUKoDZedAM7nULd2Ket2rfgzKXv2F37M48F8bWBQzTUf5/image2.png) Example: The user wants to add a new withdrawal route. Notice that percentage is shown multiplied by 100, that is '"percent": 100' means '1 percent' `clive process withdraw-routes set --to guest4test2 --percent 1 --sign alias1 --password alicealice` ![image1.png](https://images.hive.blog/DQme1fZv9QhDjz9xzbJQi7U5S8SoYBzdoggyQmkMZ146Wzj/image1.png) ##### Delegate vesting shares The user may delegate their own shares using [delegate_vesting_shares_operation](https://github.com/openhive-network/hive/blob/master/doc/devs/operations/40_delegate_vesting_shares.md) via subcommands of `clive process delegations`. The user may delegate an amount in HP or VESTS. In CLI Clive the user may set or remove a delegation. ![image10.png](https://images.hive.blog/DQmSjJn2xW5sUPCo5HrG5TUzuwKEYW84R7JtUUCwBWcoE8L/image10.png) Example: The user wants to add a delegation. The user wants to see how the operation looks, without broadcasting it. `clive process delegations set --delegatee guest4test4 --amount "0.6 hive" --no-broadcast` ![image3.png](https://images.hive.blog/DQmP7dGaB4mDLHEBayjucNQygJiH1yVH6fPfPZdr8yixyT9/image3.png) [Command schema](https://gitlab.syncad.com/hive/clive/-/blob/master/clive/__private/cli/commands_structure.md) [Complete list of corrected issues](https://gitlab.syncad.com/hive/clive/-/releases/v1.27.5.10) More info about running Clive can be found here: [Clive - alpha release](/@thebeedevs/clive-alpha-release). Please make sure you are using the most recent version: **v1.27.5.10** ## TL;DR ``` docker run -ti hiveio/clive:v1.27.5.10 ``` ### Your feedback is invaluable and always welcome.
