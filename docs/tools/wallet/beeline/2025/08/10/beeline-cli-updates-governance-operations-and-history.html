Beeline CLI Updates: Governance operations and history

Aug 10, 2025 • beggars

Work continues on the Beeline CLI, a CLI for interacting with the Hive blockchain

@beggars
Work continues on the Beeline CLI, a CLI for interacting with the Hive blockchain. The end goal being you can completely forgo a web browser and interact with Hive using the CLI (still a few more features to go before everything is covered). In this release I've added in a couple of important features that were missing. ## Governance operations You can see who you're currently voting for witness, proxies and your voting power. ![Screenshot 2025-08-11 at 10.50.17 am.png](https://files.peakd.com/file/peakd-hive/beggars/23tv4GqHPSs33iW4d7Ck1UXRhQJZR1t46Tja9hrXe3NZnUPPtJ98i6PVGLgeu2zjnGCtZ.png) List the current witnesses by ranking: ![Screenshot 2025-08-11 at 10.50.45 am.png](https://files.peakd.com/file/peakd-hive/beggars/23u5SwNNsB9zjHJ7X6S5h61AtrRX7rK25HwTmxEr4L4K1XmsQsAhRQGwfrKhWv2YYBtoj.png) Cast witness votes: ![Screenshot 2025-08-11 at 11.12.25 am.png](https://files.peakd.com/file/peakd-hive/beggars/23u5SaWyU2RXxTfnUdr48VtZFYXZ3cjTT31pHpsMgKbahYd7mAHJwmnLzPZ4rUmfwc3P8.png) All of these operations using your keys and protected by the pin code that you setup during initial setup. ## History You can now perform history commands on your account or other accounts. Allowing you to filter by type (so you can see votes, etc). ![image.png](https://files.peakd.com/file/peakd-hive/beggars/Eo6BD9cNWygYmmNNNehJngQ9jUoUCdrtDtL82gnN4zj81PePeAMhFFMm7B1ugQ3d8wU.png) You can even supply the `--format json` flag to get back the results in JSON format: ![image.png](https://files.peakd.com/file/peakd-hive/beggars/23tRtVtP9EjshVXz3DVCkmBgxAxGNMBw8jMAwq5SdWJATke6fPfME69gH3a7dpGWCQHdh.png) See specific history events like transfers: ![image.png](https://files.peakd.com/file/peakd-hive/beggars/23tkdrHz8vvadjBmPcRgHHtdKo2eijf3nZXh6EpLg3e5HJPNpNEpghcwA7KzhdLqvhrvm.png) ## More to come While the CLI is pretty feature-rich and complete, there is still more to come to make it even better. The ability to generate invoices with QR codes and other fun features I plan on adding into the CLI. I want it to be more of an operating system for Hive than a CLI. The code is available on GitHub here: https://github.com/Vheissu/beeline and contributions are welcomed. Expand the code, create your own plugins or even your own CLI based on what I've done. It's entirely open-source.
