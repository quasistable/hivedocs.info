[Alpha Release] Messaging Widget

May 2, 2023 • peak.open

Tutorial on how to add and optionally customize the messaging widget

@peak.open
![messaging_widget.png](https://files.peakd.com/file/peakd-hive/mozzie5/23ynUJD53BjD3qjNe1hRT6EdcsEqUzyZfXveWxq3JuxcCAZBpHpEmZkfBadtpzgUV4aAo.png) Around month ago PeakD String chat have been released for alpha testing. If you haven't given it a try, feel free to visit https://chat.peakd.com and check out the [previous announcement post](https://peakd.com/hive-152386/@peak.open/inviting-everyone-to-test-encrypted-chat-on-hive). Today is the alpha release day for the **messaging widget**. This post will serve as a tutorial on how to add it with few steps and optionally customize it in [the widget editor](https://chat.peakd.com/widgettest). ![customize the widget in editor](https://files.peakd.com/file/peakd-hive/mirafun/23t88FNztKaw7aqgvsomJ2sYxWk8c9bwzgkuXTznnkasRhe32319HHtgtqz16DN6JxAko.png) **About the messaging widget:** - Supports encrypted direct & group messages - Community chat channels - Keychain login/guest account - Customizable UI - Themes ## How to add messaging widget to a website **Step 1. stwidget.js lib** Download and host (preferred) or add script: https://chat.peakd.com/stwidget.js (Also available on [gitlab](https://gitlab.com/peakd/sting-message-frontend/-/raw/dev-igor/public/stwidget.js)) **Step 2. Use the generated code from Widget Editor or from the example below:** Generate the code with customization through [the widget editor](https://chat.peakd.com/widgettest) or copy the example on how to embed the widget with JavaScript shown below. ``` <!DOCTYPE html> Widget Embed Example

Widget Embed example

You can further customize by tweaking properties. Check out the property editor, send feedback and feature requests in the chat window above or open in new window.

``` The code example above and other examples on how to overlay the widget and show/hide it on a click of a button in JavaScript or Vue are [available here](https://gitlab.com/peakd/sting-message-frontend/-/tree/dev-igor/examples). **Further Customization** Feel free to post customization ideas in the chat: https://chat.peakd.com/t/hive-163399/0 **Alternatively** Clone the open source [frontend repository](https://gitlab.com/peakd/sting-message-frontend/-/tree/dev-igor/ ) and host the widget on your domain to customize it as you see fit. While not alpha released yet, there is a [frontend/backend library](https://gitlab.com/peakd/sting-message-backend/-/blob/progr-am7/libs/stlib/README.md) that can be used to communicate with the messaging backend nodes to read and post messages. --- ![Selection_298.png](https://files.peakd.com/file/peakd-hive/peakd/w36DQpO7-Selection_298.png) ## How to support Peak Open Project **WORK WITH US** If you're a project looking to integrate one of these tools message us.
