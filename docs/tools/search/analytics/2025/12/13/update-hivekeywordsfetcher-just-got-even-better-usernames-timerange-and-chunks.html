Update! HiveKeywordsFetcher just got even better! Usernames, Timerange and Chunks!

Dec 13, 2025 • louis88

Some time ago, I created a small tool that lets you search for posts on the Hive blockchain using specific keywords

@louis88
![595shots_so.png](https://files.peakd.com/file/peakd-hive/louis88/23tkhyPPFiLVhnc1Nkw9mCbTxcy8SRVd812ATCgUyJSAVRACFbdCNSqxLGiLYyPAgQDsw.png) Hey everyone! Some time ago, I created a small tool that lets you search for posts on the Hive blockchain using specific keywords. The idea was to help people quickly find posts that include certain words or phrases. Since the first version of the tool, I have spent more time working on it and adding more useful features. Today, I released some updates that were requested by the community. One of the most wanted features was the ability to search within a custom date range. This is now possible, but for performance reasons, it is currently only available when searching posts from a specific user. I also added more options for time range selection, including useful presets like the last 1,2,3,4,5 Months, and even the past year. To improve performance even more, I added something called "chunking." This means that if you search over a longer period of time, the tool will automatically split the search into smaller 30-day blocks. This helps avoid timeouts in the hafSQL database requests and keeps the tool stable and fast. These changes make the tool much more powerful and useful, especially for curators, moderators, or anyone looking to monitor specific topics or keywords on Hive. As always, you can find and use the tool for free at: ### 👉 https://hive-keyword-search.onrender.com Feel free to test the new features, and let me know if you have more ideas. I really enjoy working on tools like this, especially when I see that the community finds value in it. ![image.png](https://files.peakd.com/file/peakd-hive/louis88/23wBxxDJq7uJDEvSGh7VWYRZYjsUb7cxwdRk86fvVyDg4UGu34AhrPxA7iC2VbjtVHeof.png) ### New Features & Enhanced Flexibility - **Custom Date Range Search:** You can now search using specific start and end dates (e.g., January 1st to March 15th) instead of just the fixed "last X days." - **Search by Author (User Scope):** You can now filter search results to see posts only from a specific author. - **Smart Chunking for Long Searches:** - Searches covering more than 90 days are automatically split into smaller, 30-day chunks. - This prevents database timeouts, and all the results are automatically merged and sorted for you. ### User Experience & Stability - Smarter Date Selector: The custom date range option is now only visible when you are using the "Search by Author" filter, keeping the interface cleaner for general searches. - Keyword Limit: The maximum number of keywords has been adjusted to 3. ### Improvements & Debugging - **Improved API Error Handling:** The system now handles JSON errors more gracefully and provides more informative error messages. - **Enhanced Debugging:** - The "Debug Information" panel now shows the SQL queries for all search chunks, clearly labeled. - An Execution Log provides real-time updates on which chunk is currently being processed. - Debug SQL is now extracted even if a specific search chunk fails, aiding troubleshooting. ### Local Development Screenshots (This wont work on the small server i think...) ![image.png](https://files.peakd.com/file/peakd-hive/louis88/23tbJmoxTrUoJbcH6YF71s9nBgQvnjtgv2ZHeXmACxKcdkDQbdN7rzNiUxmwYE1qgPFDZ.png) ![image.png](https://files.peakd.com/file/peakd-hive/louis88/Eo6AogepHEEBhhhBsQxo39Qa85uAthaS7oqPWrtzL1JZ3bgCFiEZutQxeTGJa65uKQw.png) Thank you very much for your feedback so far! I look forward to receiving more and, of course, your support for my work.
