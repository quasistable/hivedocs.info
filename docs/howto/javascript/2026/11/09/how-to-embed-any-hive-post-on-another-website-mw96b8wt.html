How to embed any Hive post on another website

Nov 9, 2026 • vikisecrets

Embed Hive posts and comments on another website using cyberspace77, with automatic iframe sizing and a static-size alternative.

@vikisecrets
Mit der neuen Cyberspace-App könnt ihr jedes beliebige Hive Posting und auch Kommentare professionell in einer anderen Website einbinden. Das Feature funnktioniert so ähnlich wie auf X/Twitter. Um einen Hive-Artikel einzubinden, öffnet diesen auf [cyberspace77.com](https://cyberspace77.com/). Dann klickt auf die drei Punkte, wählt "Embed post" aus, und kopiert den Code auf eure Website. Voilà! Habe technisch mehrere Varianten getestet, dieses Feature zu implementieren. Anfangs nur mit einem iframe. Das Problem ist bei iframes allerdings, dass man die Größe im Nachhinein vom eingebundenen Frame aus nicht ändern kann, und das ist vor allem bei Posts von sozialen Medien ein Problem, da diese unterschiedlich lange sind und sogar im Nachhinein durch Edits die Größe verändern können. Daher benötigt man ein Hilfsskript, das die Postings in der richtigen Größe dynamisch einbindet. Theoretisch kann man das Posting auch ohne Skript einbinden, wenn man die richtige Größe des iframes statisch setzt, was allerdings aus obigen Gründen nicht empfehlenswert ist. Das Posting selbst ist aber wieder in einem iframe, in diesem Fall, was Vorteile in Bezug auf die Sicherheit hat. Nur ein kleines Open-Source-Skript muss dazu im Kontext der Website laufen, das man auch jederzeit nachprüfen kann. Habe mich designtechnisch im Moment gegen ein starkes Branding des Embed-Frames entschieden, damit man Hive-Artikeln auch professionell zum Beispiel auf News-Seiten einbinden kann. Ein zu starkes Branding oder ein zu auffälliger Krypto-Bezug könnte Newseditoren abschrecken. Der Inhalt und der Autor des Postings sollen im Vordergrund stehen. Was sagt ihr dazu? Habt ihr dieses Feature auf Hive auch vermisst? Wolltet ihr schon einmal ein Posting außerhalb von Hive irgendwo einbinden? ![image.png](https://images.hive.blog/DQmSuoNex5rK9yL1G9oF57Dw39Wem556Dr43ptcRyZbf7e7/image.png) https://cyberspace77.com/ @cyberspace77 ## English With the new Cyberspace app, you can professionally embed any Hive post, including comments, into another website. The feature works similarly to how it does on X/Twitter. To embed a Hive article, open it on [cyberspace77.com](https://cyberspace77.com/). Then click the three dots, select “Embed post,” and copy the code to your website. Voilà! I’ve tested several technical approaches to implementing this feature. Initially, I used only an iframe. The problem with iframes, however, is that you can’t change the size of the embedded frame afterward, and this is especially an issue with social media posts, since they vary in length and can even change size later due to edits. Therefore, you need a helper script that dynamically embeds the posts at the correct size. Theoretically, you could embed the post without a script by statically setting the correct size of the iframe, but this isn’t recommended for the reasons mentioned above. The post itself, however, is embedded in an iframe, which offers security benefits. Only a small open-source script needs to run within the website’s context, and you can verify it at any time. From a design perspective, I’ve decided against heavy branding of the embed frame for now, so that Hive articles can be embedded professionally on news sites, for example. Branding that’s too strong or a crypto reference that’s too conspicuous could deter news editors. The content and the author of the post should take center stage. What do you think? Have you also missed this feature on Hive? Have you ever wanted to embed a post somewhere outside of Hive?
