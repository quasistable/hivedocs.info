🚀 Hive React Kit Update — A Buzzing UI Upgrade for the Hive Community 🐝

Oct 15, 2025 • sagarkothari88

Buzzing update🐝Added CommunityDetails, ActivityList, Followers & Following lists — now with pagination, docs & fresh Ux

@sagarkothari88
Hello Hive Community Members, In my [last 2 last post](https://peakd.com/hive-139531/@sagarkothari88/hive-daily-dapps-dev-updates-hivereactkit-experiments-dev-lols-and-next-level-hive-power), we talked about hive-react-kit package that we are building. [In last post](https://peakd.com/hive-139531/@sagarkothari88/hivereactkit-updates-a-buzzing-update-from-the-hive) we talked more about components we delivered. In this post, today, we talk more on that. My team & I are actively building these components so that devs on hive don't have to start from scratch. With this post, I share status update on hive-react-kit by providing details on completed components followed by screenshots. ### 🏗️ Implemented `CommunityDetails` Component We’ve built something *sweet* for the Hive front end! 🍯 The new **CommunityDetails** component comes loaded with **4 power-packed tabs**: - 📝 Posts - ℹ️ About - 👥 Subscribers - ⚡ Activities **API Integrations**: `list_subscribers`, `get_accounts`, `get_ranked_posts`, `account_notifications` **Enhancements:** - Refactored to use `PostFeedList` for posts. - Updated `PostFeedList` to **always show the sort dropdown** via `showSortDropdown = true` prop. Because sorting should never hide! 😉 ### 🖼️ Sneak Peek — CommunityDetails in Action! ![image](https://hackmd.io/_uploads/BJE5K6iale.png) ![image](https://hackmd.io/_uploads/HJjsF6sTee.png) ![image](https://hackmd.io/_uploads/S1lpFaoTgx.png) ![image](https://hackmd.io/_uploads/SkbRK6s6gg.png) ![image](https://hackmd.io/_uploads/B1u-cajTxl.png) ![image](https://hackmd.io/_uploads/HJwEjpjaxx.png) ![image](https://hackmd.io/_uploads/BJFHsTsTex.png) ![image](https://hackmd.io/_uploads/H1kDjaoTlx.png) ![image](https://hackmd.io/_uploads/ryXOiTiTll.png) --- ### 💥 Improvements — Post Feed List (Trending / New / Hot) Paging, fetching, and scrolling now smoother than ever 🍃 Key upgrades: - 🔄 **Pagination Support** via `start_author` and `start_permlink` — keeps fetching until the hive runs dry 🐝 - ✳️ Added states: `hasMore`, `loadingMore`, `observerRef` - ⛏️ Enhanced `fetchPosts`: handles both fresh loads and infinite scroll appends - ⏳ “Loading more posts…” indicator while paging - 🔁 Reset pagination when the sort changes - 💡 Invisible sentinel for intersection detection = seamless scroll loading --- ### 🧮 FollowerList Component — The Hive Math Squad is Here! 🧠 Say hello to the **responsive FollowersList component**, complete with: - 📱 Dual layouts: Desktop **table view** & Mobile **card view** - ⚡ HP calculation using vesting shares + blockchain data - 💲 Vote value in USD (because hive power = real power!) - 🗓️ Smart date handling — relative or absolute depending on context - 💅 Fully responsive & mobile-friendly design Also added to demo page with props and expanded user type support! 🎨 --- ### 🫶 FollowingList Component — Friends, Everywhere! 🌍 Built on the FollowerList foundation, because who doesn’t love consistency? 😄 Now featuring: - 👤 Table & card layouts (desktop vs mobile) - 🌐 Details include avatar, username, location, about, last post, HP, and vote values - ⚙️ Dropdown menu: Add/Remove from lists & Unfollow options - 💻 Responsive design for all devices - 🧩 Event callbacks for: `onClickAuthor`, `onClickAddRemoveFromLists`, `onClickUnfollow` --- ### 📚 Docs, Docs, Docs! 🧾 You asked, we delivered! Comprehensive documentation added for both **FollowersList** and **FollowingList**: - `docs/FollowersList.md` and `docs/FollowingList.md` — complete with examples & props. - 💡 Accessibility, performance, and styling sections included - 🔍 Error handling & responsive design best practices - 💻 Real usage examples with integration scenarios --- ### 🔥 New `ActivityList` Component — Hive in Motion! ⚡ A brand new **ActivityList** component that gives you the full story of user actions: - ♾️ Infinite scrolling for non-stop hive action - 🔍 Filters by direction, type, or reward - 🗂️ Search for any specific activity - 🔓 Expandable activity details - 🌗 Fully responsive with **dark mode support**! ### 🌈 Preview Images Take a peek at the action 🕵️‍♂️ ![Screenshot 2025-10-14 at 11.16.38 AM](https://hackmd.io/_uploads/r1iw8Dsplx.png) ![Screenshot 2025-10-14 at 1.53.06 PM](https://hackmd.io/_uploads/SJg5Aqopxx.png) ![Screenshot 2025-10-14 at 1.52.53 PM](https://hackmd.io/_uploads/r1l5R5opll.png) ![Screenshot 2025-10-14 at 3.30.35 PM](https://hackmd.io/_uploads/rJNr-sjalg.png) ![Screenshot 2025-10-14 at 3.30.45 PM](https://hackmd.io/_uploads/HyESbosTlg.png) ![Screenshot 2025-10-14 at 7.00.46 PM](https://hackmd.io/_uploads/Hk6sl0jTgg.png) ![Screenshot 2025-10-14 at 7.00.34 PM](https://hackmd.io/_uploads/BJTsgAsagl.png) --- ### 🐝 Wrapping Up This release is packed with UI upgrades, React magic ⚛️, and smooth data handling.
