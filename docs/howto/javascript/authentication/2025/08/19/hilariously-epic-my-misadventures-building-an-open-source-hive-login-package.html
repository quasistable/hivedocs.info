🚀 **Hilariously Epic: My Misadventures Building an Open Source Hive Login Package!** 🐝💻

Aug 19, 2025 • sagarkothari88

Follow my emoji-filled journey building an open-source Hive login package – with memes, open source vibes & UI upgrades

@sagarkothari88
### 👋 **Hey Hive Legends!** Hope you all had an *awesome* weekend! 😎 In my last post, I shared the woes of integrating aioha into our project. TL;DR: it was a bumpy ride! So—in classic developer fashion—I decided to cook up my **own** package... just for fun (and the memes). Today, I’m serving you all the juicy details 🍕 plus my blunders, breakthroughs, and a sprinkle of open source goodness! --- ### 🎉 **Stage 1: Creating an Open Source Repo** ![step-01.png](https://files.peakd.com/file/peakd-hive/sagarkothari88/23swe9dSNxVvg471kWQPZ26SWrVBjZsWdu3UfzTA3DLzHmPce78h6NhGVaxVDvrsXwnaS.png) First up, big moves: public repo time! Dashed to GitHub and birthed a shiny new home for my ideas. --- ### ⚡️ **Stage 2: Project Kickoff with Vite** ![step-02.png](https://files.peakd.com/file/peakd-hive/sagarkothari88/Eo44LD9bfDZkuLGy3ryXYcSaHvBuq1bqGN5EFFga5LqFkJA8KgBmo4RsXofmMMQxdf6.png) Next stop: project scaffolding with Vite—the real MVP. Seriously, Vite + ReactJS + typescript = productivity BOOST! 💪 --- ### 📦 **Stage 3: The Essentials – Package Install Party** Packages I embraced in my project: - `"hive-auth-wrapper": "^1.0.0"`, - `"keychain-sdk": "^0.9.4"`, - `"buffer": "^6.0.3"`, - `"tailwindcss": "^4.1.12"`, - `"@tailwindcss/vite": "^4.1.12"`, **Why? Curious? Here’s the scoop:** - `hive-auth-wrapper`: 🐝 HiveAuth login power! - `keychain-sdk`: 🚪 Unlocks HiveKeychain in-app. - `@esbuild-plugins/node-globals-polyfill`, `@esbuild-plugins/node-modules-polyfill`, `buffer`: Make Keychain SDK play nice with React. --- ### 🎨 **Stage 4: Let's Build That Login-UI** ![step-03.png](https://files.peakd.com/file/peakd-hive/sagarkothari88/23tGVdQvjHL6KuWhs7mqYoxy8hZn7qeVqqiVXAaBcEPCQgFPiaM9F93ZayTsC5XExsCDN.png) Crafted a *fancy* modal: avatar? ✔️ Username field? ✔️ Plenty of buttons? ✔️ Version 1 felt like assembling IKEA furniture... without instructions! 🪛😅 --- ### 🎯 **Stage 5: UI Evolution – Login Options Arrive** ![step-04.png](https://files.peakd.com/file/peakd-hive/sagarkothari88/23tkfToo4nxcNf1ifhLtuUqfMR8PaiDwasvBCoZcgGD8RZsHYFVneVquGpuDBrBomzyme.png) Iteration 2: Dropped in login options galore: - Keychain - HiveAuth - Private posting key FYI: NON-functional buttons at this stage. UI first—logic after! 🤖 --- ### 📱 **Stage 6: Iteration 3 – Icons & Mobile Friendliness** ![step-05.png](https://files.peakd.com/file/peakd-hive/sagarkothari88/23wq66iEgb7BfH6wkTbxEyEH5rwqFz6TGLS1CZ8NyZzQMnzXrGPazU6YaSNkwL96ZQQbC.png) Added icons before each login option, re-jigged buttons, and—voilà—mobile-ready! Because, let’s be honest, we all code from our phones at some point. 🤳 --- ### 🔐 **Stage 7: Iteration 4 – Private Key UI & State Chaos** ![step-06.png](https://files.peakd.com/file/peakd-hive/sagarkothari88/23w276B6YSekJvs3BUuFDvRMH7mbhTeVHY4c5GdQweZiiMh35chwcuVH8kK7KgBTfhtL9.png) Added UI for “login with private posting key”. But here’s a meme to sum up the struggle: ![forced to use reactjs meme](https://media.tenor.com/xBN0gTnf1XMAAAAC/he-was-forced-react.gif) Managing React state? More like herding cats! 🐈 So many components: - Username field (now with *avatar action*) - Password field (plus key-image avatar) - Login options (icons + radio group) - Parent managing ALL state - Child hustling hard to update stats React newbies, I see you. Solidarity. 🤝 --- ### 🌈 **Open Source FTW!** ![Open source meme](https://media.tenor.com/smOFBj4VakkAAAAC/spongebob-rainbow-open-source-opensource-linux.gif) Everything here? 100% open source.
